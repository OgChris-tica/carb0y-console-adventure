# Carb0y Console Adventure

## Overview
Carb0y Console Adventure is a Unity-based game developed using C#. The project focuses on implementing interactive gameplay mechanics, structured scripting, and problem-solving within a game development environment.

## Features
- Encouragement system using in-game pillars
- Dynamic object behavior and interaction
- Color and shape-based gameplay mechanics
- Structured and modular C# scripts
